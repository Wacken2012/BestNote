# 🚀 Release v2.1.0 — Import-Preview, Backup & Retention

### ✨ Neue Funktionen
- Mitglieder-Import mit Vorschau (dry-run)
- Modal zeigt Anzahl neuer und aktualisierter Mitglieder
- Persistenter Import via POST /api/members/import

### 🔒 Sicherheit & Datenhaltung
- Option „Backup vor Import“ im UI
- Server erstellt timestamped Backup-Dateien
- Retention-Policy: nur die letzten N Backups werden behalten (konfigurierbar via MAX_BACKUPS)

### 🧪 Tests & Qualität
- Neue Tests für Import-Endpunkt, Backup-Erstellung und Retention
- Test-Suite vollständig grün: 16 Dateien, 53 Tests

### 📚 Dokumentation
- Fortschritt dokumentiert in behind-the-scenes.md
- PR #3 (merged) enthält alle Änderungen

**Breaking Changes:**
- Import endpoint changed to `/api/members/import`
- Auth store now used in router guards

**Migration:**
- Update any custom import flows to use the dry-run preview
- Ensure `server/data/backups/` exists and is writable for retention to work
